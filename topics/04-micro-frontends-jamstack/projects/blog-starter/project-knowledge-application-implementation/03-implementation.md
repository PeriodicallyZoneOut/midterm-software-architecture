# Cách kiến trúc hoạt động trong project

- [ ] Vẽ luồng bình thường và diễn giải bằng chữ.
- [ ] Chỉ vị trí handler/validation/business logic/persistence và API contract.
- [ ] Giải thích transaction/concurrency/ordering theo thực tế.
- [ ] Vẽ failure path, timeout, retry, recovery và giới hạn.
- [ ] Ghi cấu hình triển khai liên quan và thay đổi local đã thực hiện.

Mỗi sơ đồ cần nhãn giao thức, hướng dữ liệu, boundary và link code.
