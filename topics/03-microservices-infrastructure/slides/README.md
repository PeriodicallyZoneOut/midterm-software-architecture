# Slides

- `slides.md`: **Slide deck trình chiếu đầy đủ 14 slide** (nội dung, bảng so sánh, code, mermaid sequence diagram).
- `outline.md`: dàn ý chi tiết và cấu trúc chủ đề.
- `speaker-notes.md`: lời thoại thuyết trình chi tiết từng slide và mốc chuyển demo.
- `assets/`: hình/sơ đồ dùng trong slide.
- `exports/`: PDF/PPTX xuất để trình bày.
