# 02. Ánh xạ Thành phần Kiến trúc & Quy cách Component Cards — Online Boutique

Tài liệu này cung cấp bảng ánh xạ toàn diện (Master Component Mapping) từ từng "hộp" trên sơ đồ kiến trúc của **Online Boutique** tới hợp đồng Protobuf (`protos/demo.proto`), biểu tượng mã nguồn (`file:line`), cấu hình runtime Kubernetes (`release/kubernetes-manifests.yaml`) và bằng chứng kiểm chứng, kèm theo **6 thẻ Component Cards (10 trường chuẩn)** theo đúng quy cách tại **Mục 4 & Mục 8 (`docs/INVENTORY.md`)** và **Mục 5 (`docs/TEAM-ASSIGNMENT.md`)**.

## Phần 2: Quy cách Chi tiết cho Từng Component Đưa vào Slide (10-Field Component Cards)

Theo đúng **Mục 8 của `docs/INVENTORY.md` (Dòng 148–150)**, mỗi component đưa vào slide và phục vụ vấn đáp đều được chuẩn hóa đủ **10 trường**:
*(1) Trách nhiệm $\rightarrow$ (2) Đầu vào/đầu ra & Contract $\rightarrow$ (3) State sở hữu $\rightarrow$ (4) Thuật toán/luồng chính $\rightarrow$ (5) Dependency/giao thức $\rightarrow$ (6) Failure/retry/concurrency $\rightarrow$ (7) File & Symbol nguồn $\rightarrow$ (8) Container/Service/DB tương ứng $\rightarrow$ (9) Bằng chứng demo $\rightarrow$ (10) Trade-off.*

---

### Thẻ Component 1: Frontend Service (`frontend` — HTTP Gateway & SSR UI)

| STT | Mục quy cách (`INVENTORY.md` Mục 8) | Nội dung chi tiết trong Online Boutique |
| :-: | :--- | :--- |
| **1** | **Trách nhiệm (Responsibility)** | Đóng vai trò **API Gateway kiêm Backend-for-Frontend (BFF)**: Nhận toàn bộ HTTP request từ trình duyệt người dùng, quản lý phiên làm việc (`shop_session-id`) và tiền tệ (`shop_currency`) qua Cookie, điều phối gọi gRPC tới 7 microservices phía sau và kết xuất giao diện HTML (`templates/*.html`). |

### Thẻ Component 3: Cart Service & Redis Cart Store (`cartservice` + `redis-cart`)

| STT | Mục quy cách (`INVENTORY.md` Mục 8) | Nội dung chi tiết trong Online Boutique |
| :-: | :--- | :--- |
| **1** | **Trách nhiệm (Responsibility)** | Quản lý vòng đời giỏ hàng theo từng `user_id` (thêm mặt hàng, đọc danh sách mặt hàng, làm rỗng giỏ hàng) và lưu trữ trạng thái nhị phân Protobuf vào Redis. |
| **2** | **Đầu vào / Đầu ra & Contract** | - **Đầu vào (gRPC Server `:7070`):** `AddItem(AddItemRequest) returns (Empty)`, `GetCart(GetCartRequest) returns (Cart)`, `EmptyCart(EmptyCartRequest) returns (Empty)` (`protos/demo.proto:23-52`).<br/>- **Giao tiếp DB:** Giao thức Redis TCP (`:6379`) qua `IDistributedCache` (`GetAsync`, `SetAsync`). |
| **3** | **State sở hữu (Owned State)** | Sở hữu duy nhất kho dữ liệu `redis-cart`: mỗi key là `user_id` (UUID string), value là mảng byte nhị phân `byte[]` của Protobuf message `Hipstershop.Cart`. |
| **4** | **Thuật toán / Luồng chính** | - **`AddItemAsync(userId, productId, quantity)` (`RedisCartStore.cs:33-66`):**<br/>  1. Gọi `_cache.GetAsync(userId)`.<br/>  2. Nếu `value == null`: Tạo mới `Hipstershop.Cart { UserId = userId }` và thêm `CartItem`.<br/>  3. Nếu `value != null`: Giải tuần tự hóa bằng `Hipstershop.Cart.Parser.ParseFrom(value)`.
