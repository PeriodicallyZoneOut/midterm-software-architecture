# Checklist cho project mới

- [ ] Tên project, nguồn/license, snapshot version.
- [ ] Kiến thức áp dụng đúng chủ đề.
- [ ] Component → contract/state → file/symbol → runtime mapping.
- [ ] Luồng bình thường, lỗi, concurrency và recovery.
- [ ] Runbook đã chạy thật, expected/actual và evidence đã lọc.
- [ ] Giới hạn và trade-off, câu hỏi vấn đáp.
